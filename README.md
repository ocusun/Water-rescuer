# 수상구조사 필기시험 모의고사

문제은행 500제에서 실제 시험과 동일하게 **7개 과목 · 총 40문제**가 무작위 출제되고, 제출 후 점수·과목별 성적·오답 해설을 확인할 수 있는 정적 웹사이트입니다. GitHub Pages 등에 저장소를 올리면 `index.html`이 바로 동작합니다.

## 완성된 기능
- **문제은행 자동 로드**: 접속 시 `data/question-bank.docx`(원본 워드 파일)를 브라우저에서 mammoth.js로 직접 파싱하여 **498문항** 로드 (500제 중 원본 문서 편집 오류로 보기가 누락된 2문항은 자동 제외)
  - 파트별: 자세 25 / 조난사고 75 / 법령 50 / 응급처치 100 / 구조기술 125 / 지도자 자질 50 / 생존수영 73
- **시험 시작할 때마다 새로운 40문제 무작위 출제**
  - PART 01 수상구조사의 자세: 3문제
  - PART 02 조난사고의 이해: 6문제
  - PART 03 관련 법령: 6문제
  - PART 04 응급처치: 8문제
  - PART 05 구조기술: 8문제
  - PART 06 지도자의 자질: 4문제
  - PART 07 생존수영: 5문제
- **문제 풀이 화면**: 진행률 바, 40개 문항 점프 도트, 이전/다음 이동, 보기 선택 시 자동 다음 문제 이동, 미응답 확인 후 제출
- **결과 화면**: 100점 만점 점수, 합격선(60점) 판정, 과목별 정답률 그래프
- **오답 확인**: 틀린 문제만/전체 보기 전환, 정답·내가 고른 답 하이라이트, 해설 표시 (488문항 해설 포함)

## 진입 URI
- `index.html` — 유일한 진입점 (파라미터 없음)

## 파일 구조
```
index.html               메인 페이지 (시작/시험/결과 3개 화면)
css/style.css            스타일
js/parser.js             docx 문제은행 파서 (mammoth.js 사용)
js/app.js                출제·채점·리뷰 로직
data/question-bank.docx  문제은행 원본 (수상구조사 필기시험 문제은행.docx)
```

## 데이터 구조
서버 없이 동작합니다. 문제은행 워드 파일을 fetch로 읽어 아래 형식으로 변환합니다.

```js
{ part: 1~7, q: "문제 지문", c: ["보기1","보기2","보기3","보기4"], a: 정답번호, e: "해설" }
```

**문제은행 갱신 방법**: `data/question-bank.docx` 파일을 같은 서식(H4 문제 제목, ①~④ 보기, 단독 원문자 정답, 해설)의 새 파일로 교체하면 사이트에 자동 반영됩니다.

## 사용 라이브러리 (CDN)
- mammoth.js 1.6.0 — docx → HTML 변환
- Font Awesome 6.4 — 아이콘
- Noto Sans KR — 웹폰트

## 알려진 제한 사항
- 원본 문서에서 보기 일부가 누락된 2문항(어린이 안전 수칙 1문항, 구명조끼 사용법 1문항)은 출제에서 자동 제외됩니다.
- docx 파싱에 1~3초가량 걸릴 수 있으며, 로드 완료 전에는 시작 버튼이 비활성화됩니다.
