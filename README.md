# 수상구조사 필기시험 모의고사

문제은행 498제에서 실제 시험과 동일하게 **7개 과목 · 총 40문제**가 무작위 출제되고, 제출 후 점수·과목별 성적·오답 해설을 확인할 수 있는 정적 웹사이트입니다.

GitHub Pages에 올리면 `index.html`이 바로 동작합니다.

## 주요 변경 사항 (2026-08-04)
- **DOCX 실시간 파싱 제거** → 미리 변환한 `data/questions.json` 사용 (로딩 즉시 완료)
- **답안 선택 시 자동 다음 문제 이동 제거** → 모든 문제를 자유롭게 풀고 마지막에 「제출하기」 버튼으로 채점
- mammoth.js 의존성 완전 제거 (더 가볍고 안정적)

## 완성된 기능
- **문제은행 즉시 로드**: `data/questions.json` (약 280KB, 498문항)
  - 파트별: 자세 25 / 조난사고 75 / 법령 50 / 응급처치 100 / 구조기술 125 / 지도자 자질 50 / 생존수영 73
- **시험 시작할 때마다 새로운 40문제 무작위 출제**
  - PART 01 수상구조사의 자세: 3문제
  - PART 02 조난사고의 이해: 6문제
  - PART 03 관련 법령: 6문제
  - PART 04 응급처치: 8문제
  - PART 05 구조기술: 8문제
  - PART 06 지도자의 자질: 4문제
  - PART 07 생존수영: 5문제
- **문제 풀이 화면**: 진행률 바, 40개 문항 점프 도트, 이전/다음 이동, 키보드 지원(←→, 1~4)
- **결과 화면**: 100점 만점 점수, 합격선(60점) 판정, 과목별 정답률 그래프
- **오답 확인**: 틀린 문제만/전체 보기 전환, 정답·내가 고른 답 하이라이트, 해설 표시
